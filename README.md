# Menoseuranta

Voi lisätä ja poistaa menoja sekä hakea niitä kuvauksen, kategorian ja kuukauden perusteella. Menot näkyvät taulukossa, ja niiden yhteissumma lasketaan automaattisesti.

Toteutettu Reactilla ja Node.js/Expressillä. Tiedot tallennetaan JSON-tiedostoon.

## Käynnistys

Tarvitset Node.js:n (22.12 tai uudempi).

```sh
npm install
npm run dev
```

Selaimessa http://localhost:5173. Komento käynnistää myös backendin.
